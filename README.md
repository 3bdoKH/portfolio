# Professional Developer Portfolio - Abdo Khairy

A modern, terminal-inspired full-stack portfolio designed for high performance and visual excellence. This project showcases web development expertise through a clean, code-centric interface.

## Tech Stack

### Frontend
- React 19
- Framer Motion (Animations)
- AOS (Scroll Effects)
- React Icons
- React Router DOM
- CSS3 (Vanilla & Custom Properties)

### Backend
- Node.js & Express
- MongoDB (Data Persistence)
- Analytics Integration

## Key Features

- **Terminal Aesthetics**: Code-inspired UI with high-contrast themes and developer-focused typography.
- **Dynamic Content**: Projects, skills, and experience sections dynamically populated via backend APIs.
- **Interactive UI**: Custom cursor effects, scroll animations, and interactive code snippets.
- **Admin Dashboard**: Secure interface for managing portfolio content and monitoring analytics.
- **Responsive Design**: Fully optimized for all device sizes with a mobile-first approach.

## Project Structure

```text
frontend/
├── public/          # Static assets and index.html
└── src/
    ├── components/  # Reusable UI sections and elements
    ├── context/     # Global state management (Theme, Analytics)
    ├── data/        # Static data configurations
    ├── pages/       # Route-level components (Admin, Login)
    ├── services/    # API integration layers
    └── styles/      # Global CSS and design tokens
```

## Getting Started

1.  **Clone the repository**
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Configure environment**: Create a `.env` file based on `.env.example`.
4.  **Run development server**:
    ```bash
    npm start
    ```
